# 夜间守护 · Night Guard

华为 Android 12+ 原生离线自律工具。每天本地时间 **01:00–08:00** 拦截选择的娱乐、流媒体应用及自动识别的浏览器。无需 Google Play 服务，不申请网络权限。

## 使用
1. 安装 APK，在应用中选择娱乐、游戏及流媒体应用。
2. 阅读权限说明，在系统无障碍设置中启用“夜间守护”。部分系统需在应用信息菜单允许“受限设置”。
3. 在华为应用启动管理中允许自动启动、关联启动和后台活动。检查权限状态，并在真机夜间实际验证。
4. 打开受限应用后，选择回桌面或申请临时使用。填写至少10字原因，等待10分钟，输入完整随机验证句，可开放一个应用5分钟。

重启会取消临时授权与未完成申请。夜间删除限制的操作在08:00后生效；新增限制立即生效。浏览器强制纳入夜间名单，不能通过应用勾选取消。

## 下载与构建
GitHub → Actions → 成功的 **Android APK** 运行 → Artifacts → **Night-Guard-APK**，下载并解压后安装APK。测试版本，无正式发布签名；不同机器的 debug 签名可能不同，升级前注意数据保留。

JDK 21、Gradle 8.9、Android SDK/API 35：

```sh
gradle :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

## 能力边界
- 依赖启用且存活的无障碍服务；普通安装无法防止卸载、强行停止、关闭权限、安全模式和调整系统时间。
- 不读取屏幕正文，仅处理窗口事件里的应用包名。临时解锁原因与最近一次记录保存在应用私有存储，不上传。
- 浏览器识别结合系统 HTTPS 处理器与常见包名；特殊浏览器需手动选择。应用内 WebView 需要限制其宿主应用。系统设置、桌面、拨号等核心界面不限制。
- 华为纯鸿蒙 HarmonyOS NEXT 不支持此 Android APK；之前西语项目记录为华为 Android 12 兼容设备。
- 多窗口、画中画、锁屏和后台管理可能影响实际效果，未经真机验证前不保证全部覆盖。

验收：01:00前已打开的受限应用应被遮罩；08:00遮罩自动消失；检查五分钟授权到期、退出重进冷静期、重启取消授权、夜间名单变更延后、权限撤销提示、来电与闹钟不受影响。

## v0.3 应用清单与界面重做

应用选择已改为独立页面：真实应用图标、按中文名称排序、名称/包名搜索、影音/社交/游戏/浏览器/工具/待分类筛选、只看已选，以及当前搜索结果的全选/清空。浏览器始终自动勾选；系统电话、闹钟、桌面和设置保留。分类依据常见包名和系统分类，**只是建议**；在每行右侧菜单可调整分类，不会自动勾选社交通讯应用。

切换筛选不丢选择，旋转屏幕保留草稿，退出未保存时提醒。已有名单和夜间待生效名单保留；夜间减少限制仍到08:00后生效。首页显示真实已选图标与数量，区分无障碍权限和服务连接状态；华为后台设置仅记录使用者确认，不伪称系统已验证。

通知继续只在01:00–08:00显示解除限制倒计时。应用依然完全离线，无账号、广告和云端统计。

自动验证包括分类/筛选与批量选择单元测试、Android lint、APK构建，以及Android 12模拟器中的搜索、选择、分类过滤、浏览器不可取消、待生效名单读取和主页显示测试。成功的push运行中，`Android-UI-Verification` artifact提供实际模拟器截图和报告；应用列表截图使用测试应用名与测试图标，**不是使用者手机应用或华为真机截图**。华为后台及实际拦截仍需真机验证。
