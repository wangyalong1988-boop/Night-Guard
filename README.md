# 夜间守护 · Night Guard

华为 Android 12+ 原生离线自律工具。每天在你设定的夜间时段（默认本地时间 **01:00–08:00**）拦截选择的娱乐、流媒体应用和浏览器，分屏和小窗中同样有效。无需 Google Play 服务，不申请网络权限。

## 使用
1. 安装 APK，在应用中选择娱乐、游戏及流媒体应用。
2. 阅读权限说明，在系统无障碍设置中启用“夜间守护”。部分系统需在应用信息菜单允许“受限设置”。
3. 在华为应用启动管理中允许自动启动、关联启动和后台活动。检查权限状态，并在真机夜间实际验证。
4. 打开受限应用后，选择回桌面或申请临时使用。写下具体原因（至少10字，不能是重复的字），冷静10分钟，输入完整随机验证句，可开放一个应用5分钟。同一晚每多解锁一次，冷静期多5分钟，最多30分钟。

重启会取消临时授权与未完成申请。夜间放宽规则（减少应用、修改时段）在当晚结束后生效；新增限制立即生效。识别出的浏览器会默认勾选，识别错了可以直接取消，或在右侧菜单改分类。

## 下载与构建
GitHub → Actions → 成功的 **Android APK** 运行 → Artifacts → **Night-Guard-APK**，下载并解压后安装APK。测试版本，无正式发布签名；不同机器的 debug 签名可能不同，升级前注意数据保留。

JDK 21、Gradle 8.9、Android SDK/API 35：

```sh
gradle :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

## 能力边界
- 依赖启用且存活的无障碍服务；普通安装无法防止卸载、强行停止、关闭权限、安全模式和调整系统时间。
- 不读取屏幕正文。为发现分屏和小窗中的受限应用，服务会读取屏幕上每个窗口所属的应用包名，因此系统会提示它可以“查看屏幕内容”。解锁原因、解锁记录和每晚统计保存在应用私有存储，不上传。
- 浏览器识别要求应用能打开任意 http/https 网址，并且是默认浏览器、声明了浏览器类别、支持网页搜索或属于常见浏览器；只会打开链接的办公、笔记、网盘类应用不再被当作浏览器。漏掉的浏览器可在分类菜单中手动标记。应用内 WebView 需要限制其宿主应用。系统设置、桌面、拨号等核心界面不限制。
- 华为纯鸿蒙 HarmonyOS NEXT 不支持此 Android APK；之前西语项目记录为华为 Android 12 兼容设备。
- 多窗口、画中画、锁屏和后台管理可能影响实际效果，未经真机验证前不保证全部覆盖。

验收：01:00前已打开的受限应用应被遮罩；08:00遮罩自动消失；检查五分钟授权到期、退出重进冷静期、重启取消授权、夜间名单变更延后、权限撤销提示、来电与闹钟不受影响。

## v0.4 修复与夜间体验

**问题修复**
- 浏览器识别更严格；识别结果只是默认勾选，可以取消，也可以改分类。新安装的浏览器会自动加入一次。
- 修复分屏绕过：此前只要夜间守护的页面在前台，拦截就会整体暂停。现在按屏幕上所有窗口判断，分屏另一半和画中画小窗里的受限应用也会被遮住。
- 降低耗电：系统查询结果缓存10分钟；白天每分钟检查一次，夜间15秒一次，只在拦截页显示时每秒刷新倒计时。临时授权到期时会准时重新检查。

**新功能**
- 可修改限制时段，支持跨午夜（如 23:30–07:00），时长 1–16 小时。夜里修改的时段在当晚结束后生效。
- 深色模式跟随系统。拦截页固定为深色夜空：被拦的应用图标变灰，显示今晚已拦下几次，以及距离解除的倒计时。
- 冷静期逐次递增；拒绝“啊啊啊啊”这类敷衍原因；冷静期内会把你写的原因再给你看一遍；验证句每次随机。
- 最近 7 晚：一次都没解锁的夜晚点亮一颗星，有解锁的是半颗，没守护的是灰点。首页显示连续安稳的晚数。只统计服务真正运行的夜晚，安装前的夜晚不计入。
- 睡前 15 分钟提醒一次；早上第一次使用手机时，推送一条昨晚的守护小结。
- 首次使用引导：首页列出还差的设置步骤，全部完成后自动隐藏。
- 解锁记录保留最近 30 次，包含时间、应用和原因。

自动验证新增：跨午夜时段、夜晚归属日期、递增冷静期、原因检查、浏览器分类纠正等单元测试；模拟器新增浏览器可取消、深色首页和夜空拦截页截图（`home-dark.png`、`cover.png`）。

## v0.3 应用清单与界面重做

应用选择已改为独立页面：真实应用图标、按中文名称排序、名称/包名搜索、影音/社交/游戏/浏览器/工具/待分类筛选、只看已选，以及当前搜索结果的全选/清空。浏览器始终自动勾选；系统电话、闹钟、桌面和设置保留。分类依据常见包名和系统分类，**只是建议**；在每行右侧菜单可调整分类，不会自动勾选社交通讯应用。

切换筛选不丢选择，旋转屏幕保留草稿，退出未保存时提醒。已有名单和夜间待生效名单保留；夜间减少限制仍到08:00后生效。首页显示真实已选图标与数量，区分无障碍权限和服务连接状态；华为后台设置仅记录使用者确认，不伪称系统已验证。

通知继续只在01:00–08:00显示解除限制倒计时。应用依然完全离线，无账号、广告和云端统计。

自动验证包括分类/筛选与批量选择单元测试、Android lint、APK构建，以及Android 12模拟器中的搜索、选择、分类过滤、浏览器不可取消、待生效名单读取和主页显示测试。成功的push运行中，`Android-UI-Verification` artifact提供实际模拟器截图和报告；应用列表截图使用测试应用名与测试图标，**不是使用者手机应用或华为真机截图**。华为后台及实际拦截仍需真机验证。
